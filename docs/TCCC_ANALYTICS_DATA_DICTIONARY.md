# TCCC Analytics Data Dictionary — Schema TCCC_ANALYTICS_1.0

This document describes the **Enterprise Analytics CSV** generated by TCCC Evaluation Suite v2.19.3.

The export is deliberately **long-form**: one row = one criterion result for one student attempt.

| Field | Meaning |
|---|---|
| `schema_version` | Export contract identifier; currently `TCCC_ANALYTICS_1.0`. |
| `record_id` | Composite unique row key: class + anonymous student + attempt + criterion. |
| `class_id` | App-generated class UUID. |
| `class_name` | Local class name. |
| `class_status` | DRAFT, ACTIVE, or CLOSED. |
| `closed_at` | ISO timestamp when class was closed. |
| `component` | Current release stores `ACTIVE_DUTY`. |
| `operational_majcom` | Supported operational/host MAJCOM selected at class creation. |
| `home_installation_id` | Stable installation ID from `installations.js`. Blank for custom/not-listed home location. |
| `home_installation_name` | Display name of home installation/location. |
| `home_installation_host_command` | Catalog host command for the selected home installation. |
| `unit` | Optional unit/organization entered for class. |
| `training_location_type` | `SAME_AS_HOME`, `INSTALLATION`, or `CUSTOM`. |
| `training_installation_id` | Stable catalog ID if training occurred at a listed installation. |
| `training_location_name` | Actual training location name. |
| `training_location_region` | State/region if known. |
| `training_location_country` | Country/territory if known. |
| `exercise` | Optional exercise/event name. |
| `course_date` | Class date. |
| `roster` | Roster/course number. |
| `scenario` | Scenario name. |
| `scenario_version` | Scenario version entered in class metadata. |
| `tier` | TCCC tier identifier. |
| `student_anon_id` | App-generated random student UUID. No student name/rank/training ID is included in this export. |
| `attempt_id` | App-generated attempt UUID. |
| `attempt_number` | 1 for initial attempt; 2 for remediation attempt when applicable. |
| `attempt_finalized` | YES/NO. |
| `attempt_result` | PASS, FAIL, or INCOMPLETE. |
| `attempt_started_at` | ISO attempt start timestamp. |
| `attempt_finalized_at` | ISO finalization timestamp. |
| `criterion_id` | Stable criterion identifier embedded in the tier content. |
| `criterion_section` | CUF/TFC/MARCH-PAWS section code used by the app. |
| `criterion_text` | Criterion text from the versioned tier snapshot. |
| `critical` | YES/NO. |
| `provenance` | Source classification stored with the criterion, including DAF supplemental where applicable. |
| `grade` | `pass`, `fail`, `nt`, `no`, or blank if ungraded. |
| `grading_method` | How the grade was created (evaluator, scenario default, timing, etc.). |
| `graded_at` | ISO criterion grading timestamp. |
| `nt_reason_code` | Structured NT reason code when present. |
| `nt_reason_label` | Human-readable NT reason when present. |
| `criterion_note` | Criterion evaluator note. Treat as potentially identifying free text and protect accordingly. |
| `timer_forced_failure` | YES if a linked timing standard forced the criterion failure. |
| `content_version` | Tier/source snapshot version attached to the attempt/class. |
| `app_version` | App version that created the attempt. |
| `export_timestamp` | ISO time the analytics CSV was generated. |

## Future compatibility

A later backend or Power BI model should depend primarily on field names and `schema_version`, not column position. If a future release changes the schema, increment the schema identifier instead of silently repurposing a field.

## Privacy note

Although student names and training IDs are intentionally excluded, criterion notes and class metadata are user-entered free text. Treat exported files according to the approved environment and local records/privacy requirements.
